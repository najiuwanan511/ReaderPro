# UI 重制：第一轮

本轮依据 legado-E 的布局资源调整页面结构，仍需 iPhone/iPad 上逐屏核对，不能视为像素一致或全部功能移植完成。

| 页面 | 参考资源（legado-E/app/src/main/res/layout） | 本轮改动 |
| --- | --- | --- |
| 书架 | fragment_bookshelf1.xml、item_bookshelf_grid.xml、item_bookshelf_grid2.xml | 分组下划线标签；封面下方书名、封面叠字、列表三种布局；排序与布局持久化；搜索及更多菜单 |
| 发现 | fragment_explore.xml、item_find_book.xml | 平铺书源行，点击展开可换行的分类标签；按需解析分类规则；筛选及搜索入口 |
| 搜索 | item_search.xml | 封面、书名、作者、书源、简介；复用书籍详情 |
| 详情 | activity_book_info.xml | 背景封面、弧形过渡、居中封面、简介、完整目录、底部加入书架/阅读；章节搜索与正倒序 |
| 阅读菜单 | view_read_menu.xml、dialog_read_book_style.xml | 上下章、页进度、目录/朗读/界面/设置；独立字体、间距、翻页、主题面板 |
| 我的 | view_preference.xml、pref_main.xml | 普通图标与标题/摘要的分组设置行，移除重复跳转箭头 |
| 书源管理 | 原有管理流程 | 顶栏集中导入入口，新增本地 JSON 文件导入，反馈解析/新增/更新/重复/跳过数量 |

搜索、发现和书架内搜索统一使用 SourceBookDetailView。完整目录不再截断到 300 章；已存在的同源同名同作者书籍复用书架记录，保留进度与已缓存的章节。漫画跳转至漫画阅读器。

同步修复上一轮 SourceEngine.swift 中导入循环缺少闭合括号、导致编译失败的问题。

## 验证

- 本地检查：Git diff 空白检查、Swift 语法树检查（第三方解析器不能代替 Xcode 编译）。
- 编译：推送 main 后由 macOS Actions 先执行 xcodebuild test，再执行 archive；测试失败不生成安装包。
- 已增加 iPhone 模拟器界面测试：校验后的常驻搜索与状态筛选、报告与重启持久化、发现→详情→完整目录→点章节直接阅读、搜索→目录。截图随测试产物保存，并单独检查正文区域确实绘制了文字像素。
- 已修复 Info.plist 被项目生成器覆盖导致的旧式屏幕尺寸和网络配置丢失，以及 TextKit 文本存储未正确连接导致的正文空白。
- 本机为 Windows；模拟器验证在 GitHub 的 macOS 运行器上执行，未进行实体 iPhone/iPad 验收，也未声称与 Android 逐像素一致。

## 设备验收步骤（待执行）

1. 空书架与有书书架：三种布局、收藏/分组、排序、搜索、本地导入、多选删除；重启后布局与排序保持。
2. 发现：大书源库滚动、展开/收起、长分类名称换行、筛选、空规则与异常规则提示。
3. 搜索/发现详情：封面加载失败占位、目录超过 300 章、搜索与倒序、直接点击章节阅读、返回后继续阅读；重复加入不新增副本。
4. 书源导入：本地单个 JSON、千条数组、重复项、错误条目、取消文件选择、网络链接及二维码，核对各项统计。
5. 阅读：窄屏/横屏/分屏，五种翻页、大小字号、行段距、主题、目录/上下章/朗读/设置；正文与页眉页脚不重叠。
6. 浅色/深色、较大系统字体、iPhone 安全区及 iPad 分屏下的菜单与底部按钮。

当前仍保留原项目中明确标注“暂未实现”的功能；默认配色、系统导航/图标与 Android 端也仍有差异。
