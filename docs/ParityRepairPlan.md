用户范围：修复功能、书源规则和界面差异；**备份与同步不纳入本次工作**。不下载、不运行 1329 书源合集。

顺序与验收：

1. 书源执行链：编辑保存、搜索分页、登录检测、目录脚本和章节标记、正文网页脚本、脚本接口与限流。使用可重复的 HTTP/脚本样例验证。
2. 搜索及发现：范围/历史、分页、长按菜单、分类布局。验证修改源后立即生效和分页无重复。
3. 阅读及媒体：选文、样式、朗读、缓存管理、在线音频、歌词/弹幕、媒体设置、漫画配置。验证选章和连续阅读/播放。
4. 订阅和书架：订阅规则、收藏/记录、规则更新、分组/追更、详情编辑及统计。
5. 设置与 UI：替换占位入口，逐屏核对；主回归与 iOS 17 Release 回归后再交付。

状态必须以实际实现和测试证据更新；未完成项不得标记为已对齐，构建通过不得视为全功能等价。

### 本轮继续修复（待新提交回归）

- `java.toURL` 按安卓 JsURL 返回相对地址解析、原始查询键、URLDecoder 查询值和 Map 访问；`ajaxTestAll` 返回每个地址的耗时及失败码，补充 `callTime`、`putCallTime`、`isSuccessful`。

- WebKit 对设备自身的可路由 IP 也可能忽略代理：补充设备网卡地址检测，拒绝代理访问本机地址，并拦截页面对这些地址的子资源请求。普通其他 IP 的代理仍允许。此为平台限制下的明确拒绝，不等于已实现本机地址的网页代理。
- 备份/同步仍排除；未运行或分析 1329 合集。
- 补上 `getThemeMode`、`getThemeConfig/Map`、`getReadBookConfig/Map`，读取当前主题与已有阅读设置，不从后台脚本同步等待主线程；阅读配置只覆盖 iOS 实际提供的参数，不能视为安卓全部样式字段已齐。订阅网页读取页面创建时的配置快照。
