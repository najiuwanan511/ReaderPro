# legado-E 对齐修复

用户范围：修复功能、书源规则和界面差异；**备份与同步不纳入本次工作**。不下载、不运行 1329 书源合集。

基线：ReaderPro `826f0cb`；legado-E `8b87c5a`。完整审计在本机 `ReaderPro-builds/ReaderPro-legado-E-功能差异审计-20261103.md`。

顺序与验收：

1. 书源执行链：编辑保存、搜索分页、登录检测、目录脚本和章节标记、正文网页脚本、脚本接口与限流。使用可重复的 HTTP/脚本样例验证。
2. 搜索及发现：范围/历史、分页、长按菜单、分类布局。验证修改源后立即生效和分页无重复。
3. 阅读及媒体：选文、样式、朗读、缓存管理、在线音频、歌词/弹幕、媒体设置、漫画配置。验证选章和连续阅读/播放。
4. 订阅和书架：订阅规则、收藏/记录、规则更新、分组/追更、详情编辑及统计。
5. 设置与 UI：替换占位入口，逐屏核对；主回归与 iOS 17 Release 回归后再交付。

状态必须以实际实现和测试证据更新；未完成项不得标记为已对齐，构建通过不得视为全功能等价。
